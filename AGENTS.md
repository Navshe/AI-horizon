

# Project instructions

- The user uses Stata 17 on macOS and does not know Python.
- Write analysis programs as Stata .do files.
- Explain how to run the commands in Stata.
- Never overwrite original data or crosswalk files.
- Save generated results in the output folder.
- Identify PUMAs using state and PUMA codes together.
— When coming up with county estimates from PUMA estimates— calculate the weighted average based on the proportion of PUMA that is in the particular county.  
- Preserve leading zeros in geographic identifiers.
- Do not upload IPUMS microdata to GitHub.
- Record important decisions and progress in log.md.
- Clearly distinguish estimated county values from directly observed values.
